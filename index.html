    Python Package Template¶

    A Python library template with uv, Pydantic settings, loguru, pytest, Ruff, Git hooks, generated API docs and Conventional Commit releases. Supports Python 3.12–3.14.8.

    Get started¶

    With Make, Bash, Git and uv available:

    git clone https://github.com/AmineDjeghri/python-package-template.git
cd python-package-template
make install-dev
make pre-commit-install
make check
make run

    This installs the editable package and tools, sets up hooks, validates the checkout and runs the example. No live service or integration credentials are required. make help lists all commands.

    Use the package¶

    Download a wheel from this repository's GitHub Releases, then install that file:

    uv pip install "/path/to/python_package_template-<version>-py3-none-any.whl"

    from python_package_template.example import hello

hello()

    Releases attach a wheel and sdist to GitHub and publish documentation on GitHub Pages; this template does not publish to a package index.
