# 1. Setup

Prepare the package, development tools and documentation environment.

## Prerequisites

Make, Bash, Git and uv on Linux, macOS or Windows with Git Bash/WSL.
uv provisions Python 3.12–3.14.8; run `make install-uv` if uv is missing.

## Install

```bash
git clone https://github.com/AmineDjeghri/python-package-template.git
cd python-package-template
make install-dev
make pre-commit-install
make check
make run
```

This creates `.venv`, installs the editable package and Git hooks, validates the checkout
and runs the greeting example. No integration service or credentials are needed.
Optionally copy `.env.example` to `.env` to customize settings such as `LOGGING_LEVEL`.

## Optional environments

| Command                | Use                                                    |
|------------------------|--------------------------------------------------------|
| `make install-tools`   | Static/docs tools without the application dependencies |
| `make install-release` | Packaging and release tools                            |
| `make docker-build`    | Build the development image                            |
| `make docker-dev`      | Open a container with this project mounted in `/app`   |
| `make docker-prod`     | Open a shell in the built image                        |

Inside the container, use `make run` and `make check`. If a mounted host `.venv` conflicts,
recreate it for the container. A manually managed environment can use `uv pip install -e .`;
that alone does not install the development tools.

## Documentation and editor

```bash
make deploy-doc-local
```

Use `.venv/bin/python` as the interpreter; mark `src` and `tests` as source/test roots.
Follow `.editorconfig` for indentation and line endings.
Hooks are installed once with `make pre-commit-install`; docs/check targets do not reinstall them.

For workflow debugging, Docker plus `make install-act` enables `make act`.
For publication, see [release credentials](5.release.md#credentials).
Next: [Conventions](3.conventions.md) and [Testing](4.testing.md). `make help` lists all targets.

Edit `AGENTS.md` to update the shared instructions.
