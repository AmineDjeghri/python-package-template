# 6. Fork this template

Start a new Python package from this repository.

## Rename

| What                           | Where                                                                                           |
|--------------------------------|-------------------------------------------------------------------------------------------------|
| distribution name, description | `pyproject.toml`: `[project] name`, `description`                                               |
| package folder                 | `src/python_package_template/`, imports in `tests/` and `docs/examples/`                        |
| console script                 | `pyproject.toml`: `[project.scripts]` (`hello`)                                                 |
| logger name                    | `settings.py`: the `name` used to bind and filter the loguru logger                             |
| Docker image name              | `makefiles/docker.mk`: `CONTAINER_NAME`                                                         |
| documentation                  | `README.md`, `CLAUDE.md`, `properdocs.yml` (`site_name`, `site_author`), `SECURITY.md`, `docs/` |
| version and changelog          | reset `project.version` to `0.1.0`, empty `CHANGELOG.md`                                        |

Then: `uv lock`, `make test-all`, `make pre-commit`.

## Once on GitHub

1. Create `main` and `dev`, and protect them (pull requests only, squash merge).
2. Workflow permissions "Read and write", and GitHub Pages from `gh-pages`
   ([5. Release](5.release.md#repository-settings-once)).
3. Install the Renovate app on the repository.

## Stay in sync with the template

Shared files: `makefiles/`, `Makefile`, `scripts/emoji_commit_parser.py`, `.pre-commit-config.yaml`,
`.markdownlint-cli2.yaml`, `.github/`, `docs/developer/`.

```bash
git remote add template-upstream https://github.com/AmineDjeghri/python-package-template.git
git fetch template-upstream
git checkout template-upstream/main -- makefiles/release.mk   # the files you want
git diff --staged                                              # review before committing
```
